# Planejamento Alexandre

Apresentação comercial para Alexandre Chaves Barcellos. Site estático, sem dependências de build.

## Abrir localmente

Na pasta deste projeto:

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

Abra `http://127.0.0.1:8765/`.

## Arquivos

- `index.html`: texto e estrutura da apresentação.
- `styles.css`: visual e adaptações para telas menores.
- `script.js`: menu compacto e indicação da seção ativa.
- `docs/stories/001-apresentacao-comercial.md`: escopo e critérios de aceitação.

Na apresentação, use o menu fixo no topo para navegar entre os capítulos. Em telas menores, use o botão **Seções**.
